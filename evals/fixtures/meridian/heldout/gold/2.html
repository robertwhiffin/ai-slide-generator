Prompt Design Patterns

Four composable patterns cover the vast majority of prompt optimisation needs

A mental model for systematic prompt engineering

  • System-prompt framing — Set the model's role, constraints, and tone up front to anchor every response
  • Few-shot examples — Supply 2–5 input/output pairs so the model learns your format by demonstration
  • Chain-of-thought reasoning — Ask the model to "think step by step" to improve accuracy on complex tasks
  • Structured output formatting — Request JSON, Markdown, or tables to cut post-processing and reduce token waste by 30–50%
When to combine: Pair few-shot examples with chain-of-thought for up to 40% better output consistency — start simple, then layer patterns as needed across 3–5 iteration cycles.
