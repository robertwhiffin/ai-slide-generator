Action Plan

Adopt this five-step checklist for every new LLM feature

A repeatable process your team can start using this sprint

  • Define task scope — Specify the input, desired output format, and constraints before writing a single token
  • Choose prompt patterns — Select from few-shot, chain-of-thought, or structured templates based on task complexity
  • Write eval criteria — Set measurable quality bars (accuracy, consistency, token efficiency) before iterating
  • Run your test suite — Validate against edge cases across 3–5 iteration cycles to reach production-grade quality
  • Document the winning prompt — Record the final prompt, rationale, and eval results so the team can reuse and improve it
Start this sprint: Apply this checklist to your next LLM feature — no new tooling required. Structured prompts cut token waste by 30–50% and boost output consistency by up to 40%.
